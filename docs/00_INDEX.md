## Important framing
The official PayPal AI Hackathon does **not** prescribe a fixed problem statement. `PROJECT_CHARTER.md` is our proposed project problem statement, written to match the contest requirement that a project meaningfully use both PayPal and AI. The demo should use PayPal Sandbox, not live money.
